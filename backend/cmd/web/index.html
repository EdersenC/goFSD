Local Parking Lab
FiveM Parking Workspace

Teach the car one parking skill at a time.

Calibrate a real bay in FiveM, collect focused forward-parking attempts, inspect live goal error, and carry the resulting data into model training.

Focused First Milestone

Forward parking, with a target you choose.

The lab uses the parked car's current position and heading as the goal pose. Choose a clear perpendicular bay, place the setup car exactly where a successful park should finish, then calibrate before collecting attempts.

Forward-only for now. Reverse, back-in, and parallel parking need an explicit drive-direction control path and are intentionally outside this first workspace.

Collect Attempts

Setup, calibrate, then collect.

1. Prepare the bay

Spawn the setup car, drive it into the final parked pose, and save that position and heading as the target.

2. Run collection

Each attempt begins from a forward-only approach to the calibrated bay. A seed makes the same attempt variations repeatable.

3. Evaluate a trained model

Spawn a Sultan inside the same seeded start envelope used for training, without capture or the GTA parking expert. Then load and start a parking checkpoint from Advanced.
